# Głucha przestrzeń

*(Ballada kolejowa)*

Interaktywne opowiadanie. Między Orszawą a Byliczem leży dwanaście kilometrów
toru, którym od roku nie przejechał żaden pociąg. Ktoś jednak musi go pilnować.

Najlepiej w słuchawkach, w ciemnym pokoju.
